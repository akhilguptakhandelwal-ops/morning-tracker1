Deployment Guide
Everything you need to run this on your machine

1. Install Dependencies

Run this once in your project directory to install all required Python packages.

pip install -r requirements.txt

2. Configure Environment

Copy the template and fill in your Gemini API key and Gmail credentials.

cp .env.template .env # Then edit .env with your values source .env

3. Required Environment Variables

Set these before running the script. Never commit them to git.

GEMINI_API_KEY=... # from aistudio.google.com SENDER_EMAIL=... # Gmail address SENDER_PASSWORD=... # 16-char App Password

4. Run the Tracker

Execute directly or let the scheduler handle it daily.

python morning_tracker.py # Management CLI python manage.py list-sources python manage.py list-recipients python manage.py reset-all-state

5. Gmail App Password Setup

Standard Gmail password won't work. You need a 16-character App Password:

1. Go to myaccount.google.com 2. Security → 2-Step Verification (enable if not already) 3. Security → App passwords 4. Select app: Mail | Device: Other (Morning Tracker) 5. Copy the 16-char password → paste into SENDER_PASSWORD
Scheduler Builder
Generate the right cron expression for your daily brief

⚙️ Build Your Schedule

Configure when the tracker should run every day.

0 7 * * * cd /path/to/project && source .env && python morning_tracker.py >> logs/tracker.log 2>&1

📋 Add to Crontab

Open your crontab editor and paste the generated expression.

# Open crontab editor crontab -e # Paste the generated line above # Save and exit (Ctrl+X in nano) # Verify it's registered crontab -l

🪟 Windows Task Scheduler (Alternative)

On Windows, use Task Scheduler instead of cron.

# Create a .bat file (run_tracker.bat) @echo off cd C:\path\to\morning_tracker set GEMINI_API_KEY=your_key_here set SENDER_EMAIL=your@gmail.com set SENDER_PASSWORD=your_app_password python morning_tracker.py >> logs\tracker.log 2>&1 # In Task Scheduler: # Action: Start a program → python.exe # Arguments: morning_tracker.py # Start in: C:\path\to\morning_tracker # Trigger: Daily at 7:00 AM

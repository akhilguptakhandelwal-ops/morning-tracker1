GitHub Setup Guide
How to get your Personal Access Token for Manual Run

Step 1 — Generate Token

Go to GitHub and create a Personal Access Token with workflow permissions.

github.com → Profile (top right) → Settings → Developer settings (bottom left) → Personal access tokens → Tokens (classic) → Generate new token (classic)

Step 2 — Select Scope

Only one permission is needed to trigger workflows.

Note: "MIT Dashboard token" Expiration: 90 days ☑ workflow ← check this only Click: Generate token Copy the ghp_xxxx... token

Step 3 — Paste in Dashboard

Go to Manual Run page and paste the token. It stays in your browser only.

Dashboard → Manual Run → Paste token in the box → Click Save Token → Click ▶ Run Now

Step 4 — Check History

After running, check the Run History page to see status, time, and duration.

Dashboard → Run History → See last 7 days of runs → Green = success + email sent → Red = something failed → Click run name to see logs
